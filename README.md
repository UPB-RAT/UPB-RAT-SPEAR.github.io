# LLMAR: Validated LLM-Generated Reward Functions for RL

A static site presenting **LLMAR** — treating reward design as constrained code
generation for reinforcement learning.

- A three-stage validator (extractability, static safety, runtime check) gates
  LLM-drafted reward functions with categorical, repairable failure codes.
- Only interface-valid code reaches a fast proxy success-rate evaluation.
- The outcome returns as DPO preferences that train the generator.
